#Streak

A minimalist Android application focused on building consistency.

One day at a time.

## Philosophy

Streak is not about motivation.

It is about consistency.

No accounts.

No ads.

No cloud.

Just your streak.

## Features

✓ Daily check-in

✓ Streak counter

✓ Calendar

✓ Statistics

✓ Material Design 3

✓ Offline first

✓ Open Source

## Tech Stack

Kotlin

Jetpack Compose

Room

MVVM

Material Design 3
